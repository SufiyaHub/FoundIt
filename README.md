# FoundIt

\# FoundIt – Lost and Found Android Application



\## 📌 About



FoundIt is an Android application that helps users report, search, and recover lost or found items. Users can upload item images and provide details such as description, location, and date.



\## 🔐 Three-Step Verification



To prevent false claims, FoundIt uses a three-step verification process:



1\. \*\*Image Upload\*\* – The user uploads an image of the item.

2\. \*\*Security Questions\*\* – The user answers three questions set by the finder.

3\. \*\*Answer Validation\*\* – The answers are verified before access is granted.



After successful verification, the finder's phone number and contact details are unlocked.



\## ✨ Key Features



\- User Login / Signup

\- Post Lost \& Found Items

\- Search \& View Listings

\- Image Upload

\- Three-Step Verification

\- Secure Contact Sharing

\- Notifications
